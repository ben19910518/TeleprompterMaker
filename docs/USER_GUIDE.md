# Teleprompter Maker v1.3.0 使用手册

本手册对应 Windows 版 v1.3.0。界面文字以简体中文为例，英文、日文界面功能相同。[返回项目首页](../README.md)。

## 1 软件用途和功能

Teleprompter Maker 将音频与带时间信息的歌词合成为提词器视频，适合演出、排练、录音或提词屏播放。基本流程是：导入音频和歌词 → 获得或修正时间轴 → 调整排版 → 保存歌词 → 导出视频。

| 功能 | 可以完成的操作 |
| --- | --- |
| 歌词导入 | 导入 LRC、SRT，或输入、粘贴、导入 TXT 纯文本 |
| 自动对轴 | 根据音频和逐行文本估计每句开始、结束时间，检查可信度并试听 |
| 歌词编辑 | 修改文字、修改起止时间、插入与删除句子、撤销与重做 |
| 时间微调 | 开始、结束分别提供 ±50ms 和 ±200ms；也可直接输入时间 |
| 播放校对 | 播放/暂停、上一句/下一句、时间轴定位、单句试听、全屏预览 |
| 视频排版 | 分辨率、帧率、背景、字体、字号、行数、间距、对齐、透明度与描边 |
| 提词效果 | 当前句强调、滚动动画、整体时间偏移、长间奏倒计时、短句合并显示 |
| 导出 | 生成提词器视频；歌词可另存为 LRC 或 SRT |
| 界面语言 | 简体中文、英文、日文；首次启动根据系统语言选择，其他语言回退到英文 |

主程序面向 Windows 10/11 64 位。已有 LRC/SRT 的排版、编辑和默认视频导出不要求 NVIDIA 显卡。自动对轴可以使用 CPU；兼容的 NVIDIA GPU 与 CUDA 环境可加速识别。

音频能否打开取决于程序内置解码器，常见 WAV、MP3、FLAC、M4A 等可优先尝试。遇到特定编码无法读取时，可先转为 WAV。软件不包含歌曲、歌词版权授权或现成歌曲素材。

## 2 下载、启动和界面语言

**当前 GitHub 首次公开发布提供源码，未附 EXE 包。** 从 GitHub 下载源码的用户，请先按第 12 节配置环境。下面的 EXE 操作适用于已取得完整 Windows 绿色包的用户；主界面的功能操作两者相同。第三方运行包发行状态见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

1. 准备完整的 `TeleprompterMaker_v1.3.0.zip` Windows 绿色包；本次 GitHub 源码发行暂不提供该附件。
2. 将压缩包完整解压到可写目录，例如 `D:\Tools\TeleprompterMaker`。
3. 双击 `TeleprompterMaker.exe` 启动。绿色版不用安装 Python，也不用启动脚本。
4. 保留 EXE 同目录的 `_internal` 等文件；单独复制 EXE 无法运行。
5. 通过右上角 **设置 → 界面语言…** 选择中文、English 或日本語，并按提示应用。

首次启动使用系统语言：中文对应中文，日文对应日文，英文及其他语言对应英文。手动选择会保存，不会每次启动都覆盖成系统语言。

GitHub 的 **Code → Download ZIP** 是源码下载入口，不是绿色运行包。

程序会保存界面语言、常用样式、窗口状态和最近使用的文件路径。它没有完整的工程文件功能；重新启动并不等于恢复全部未保存的歌词修改。请主动保存歌词，并保留原始音频。

## 3 第一步：导入与对轴

![第一步界面](images/step-1-import.png)

### 3.1 准备音频和歌词

点击音频区域的 **选择…**，也可以把音频文件拖入窗口。加载成功后会显示路径和时长。

歌词有两种准备方式：

- 已有时间轴：导入与音频版本一致的 LRC 或 SRT。
- 没有时间轴：导入 UTF-8 文本，或在左侧直接输入、粘贴歌词，每行一句。

自动对轴时，歌词应与实际演唱顺序一致。重复演唱的副歌需要重复填写；删除歌名、作词作曲信息、说明文字和没有演唱的行。不要只写“副歌重复”来代替真实歌词。

**粘贴** 会用剪贴板内容替换左侧文本，**清空** 会清空左侧文本。切换音频后需要重新检查识别结果与时间轴是否对应。

### 3.2 已有 LRC/SRT：跳过识别

1. 选择音频。
2. 点击 **导入文件…**，选择 LRC 或 SRT。
3. 检查绿色提示是否显示“已带时间轴”。
4. 点击 **已有时间轴，直接下一步 →**。
5. 到第二步试听，确认歌曲版本、前奏长度和时间轴一致。

右侧识别结果为空并不代表导入失败：该区域主要显示自动识别生成的结果。已有歌词会在第二步的原歌词列表中显示。

纯 TXT 没有真实时间轴；临时预览不能代替对轴结果，不应直接用于正式导出。

### 3.3 纯文本：自动生成时间轴

1. 导入音频，把逐句歌词放入左侧。
2. 选择识别语言。可选自动检测、中文、粤语、日文、英文、韩文；已知语言时可直接指定。
3. 选择模型。Large-v3 Turbo 约 1630MB，通常优先用于准确性；Small 约 490MB，适合先试跑或资源较少的机器。
4. 若模型尚未下载，按界面提示下载。可根据网络情况选择 ModelScope、Hugging Face 或 hf-mirror 来源。
5. 点击 **开始识别**，等待进度完成。需要中止时点击 **取消**。
6. 检查右侧的开始、结束、歌词和可信度。橙色行表示没有听清、采用估算等情况，应重点试听。
7. 选择结果行并点击 **试听选中行**；双击时间单元格可修改时间。确认不需要的结果行后，可删除选中行。
8. 可先点击 **保存为 LRC…** 或 **保存为 SRT…** 单独保留结果。
9. 点击 **应用并进入下一步 →**，将结果用于主界面的排版与微调。

自动识别是校对起点。伴奏较响、和声、漏唱、改词、混合语言或歌词顺序不一致，都可能影响结果；高可信度也不能代替试听。

### 3.4 应用结果时如何保存

应用对轴结果时，程序会尝试保存一份 LRC。通常使用原 TXT 或音频的文件名作为基础，文件已存在时使用带“自动识别”的新名称，避免直接覆盖原歌词。

若自动保存失败，结果仍可进入编辑状态；请使用 **另存歌词…** 保存到可写目录。此后手工微调不会持续自动写回文件，需要主动保存。

## 4 第二步：格式、预览和定位

![第二步界面](images/step-2-edit.png)

页面左侧是排版参数与输出路径，右上是画面预览和播放控制，右下是原歌词列表与本句微调。右上角可切换 **简易模式 / 详细模式**，详细模式展开更多参数。

1. 点击 **播放** 或按空格试听。
2. 用 **上一句 / 下一句** 在歌词之间定位。
3. 在时间轴上点击或拖动，跳到相应位置。
4. 时间轴定位到高亮句时，下面原歌词列表会选中并滚动到对应句，本句微调区域同步显示该句。
5. 点击原歌词列表中的一行，也可以定位到该句。
6. 勾选 **跟随播放选句**，播放时让下方选句跟随当前进度；编辑输入框期间会避免频繁抢走选句。
7. 点击 **全屏预览** 检查实际显示效果；有第二显示器时会优先用于预览，按 Esc 退出。

时间轴用于播放定位，当前版本不提供通过拖动句子边缘直接修改起止时间的操作。修改时间请使用本句微调区。

点击 **← 重新对轴** 可以返回第一步；顶部步骤按钮也可以切换页面。返回前注意保存已有修改，重新应用识别结果会替换当前时间轴。

## 5 逐句编辑和时间微调

### 5.1 选句并修改文字

1. 暂停播放，在时间轴或原歌词列表中选择目标句。
2. 确认下方高亮行和“第几句”提示正确。
3. 在右侧文字框修改内容。
4. 点击 **应用修改**，再试听检查。
5. 点击 **保存歌词** 写入文件。

切换句子、保存等操作会尝试提交当前有效输入。建议先点击应用，避免把未确认的文本当成已保存结果。

### 5.2 开始、结束分别微调

| 按钮 | 效果 |
| --- | --- |
| 开始 −50 / −200 | 当前句开始提前 50 / 200 毫秒 |
| 开始 +50 / +200 | 当前句开始推迟 50 / 200 毫秒 |
| 结束 −50 / −200 | 当前句结束提前 50 / 200 毫秒 |
| 结束 +50 / +200 | 当前句结束推迟 50 / 200 毫秒 |

50ms 与 200ms 按钮上下排列。先用 200ms 大致调整，再用 50ms 修正。比如歌词比人声晚约 250ms，可把开始先减 200，再减 50；需要改变显示结束时刻时，再单独调整结束。

也可以直接输入 `00:12.350` 这样的时间。界面单位为毫秒；负数、无效时间、结束早于开始等输入会被校验，操作可能被限制在允许范围。

### 5.3 用播放位置打点

1. 播放或定位到目标句实际开始的位置，暂停。
2. 点击 **此刻设为开始**。
3. 定位到该句实际结束的位置，点击 **此刻设为结束**。
4. 使用 ±50ms 做最后修正，再点击 **试听本句**。

编辑区显示的是歌词原始时间，不包含“整体偏移”。打点时程序会换算偏移，避免把偏移重复计入歌词。

### 5.4 自动结束时间

结束框留空表示自动计算，一般根据下一句开始时间推算；末句会结合音频时长等信息处理。列表中的“自动”表示这个结束时间没有作为显式句尾保存。

开始必须早于结束，句尾还受下一句开始时间约束。出现限制时，先检查相邻句的时间，而不是反复点击按钮。

### 5.5 插入、删除、撤销与重做

- **后插一句**：在当前句后新增一行，再填写文字和时间。
- **删除本句**：删除当前选择的原歌词行，删除前确认行号。
- **撤销 / 重做**：恢复或重新执行歌词编辑操作；历史只保留在当前运行期间，最多约 100 步。
- 文本框内的 Ctrl+Z 使用文本编辑器自己的撤销；歌词列表中的 Ctrl+Z / Ctrl+Y 用于歌词编辑历史。

## 6 画面与导出参数

建议先用简易模式完成视频，再按需要切到详细模式。隐藏的详细参数仍可能影响当前样式。

### 6.1 画面和文字

| 设置 | 用途和操作建议 |
| --- | --- |
| 分辨率 | 常用 1920×1080 横屏；竖屏可选 1080×1920。自定义尺寸支持 160～7680 像素范围 |
| 帧率 | 常用 25、30、60fps，也支持 23.976、29.97、59.94 等；帧率越高通常计算量越大 |
| 背景颜色 | 黑色适合提词屏；绿幕、蓝幕便于后期抠像，也可选自定义颜色 |
| 字体、字重 | 选机器上可用且能完整显示歌词语言的字体；详细模式可加载字体文件 |
| 自动铺满屏幕 | 根据可用空间计算字号；取消后可手动指定字号 |
| 上下行比例 | 控制非当前句相对当前句的字号，让当前句更醒目 |
| 字间距、行间距 | 调整字与字、句与句之间的距离；长句挤压时先检查字号与换行 |
| 显示行数 | 控制画面中显示的歌词行数，支持 1～21 行 |
| 对齐、边距 | 详细模式可设左/中/右对齐及画面留白 |
| 当前行位置、换行 | 调整当前句垂直位置、长句最多换行数及换行间距 |
| 颜色、描边 | 设置文字颜色和轮廓，帮助文字在目标背景上保持可读性 |
| 透明度、边缘淡出 | 控制邻近句、远处句、已唱句亮度及边缘过渡 |

字体文件可放到程序的 `fonts` 目录，启动时加载；也可在详细模式手动加载。换一台电脑后，系统字体可能不同，导出前应重新检查预览。

### 6.2 动画和时间

| 设置 | 作用 |
| --- | --- |
| 滚动动画 | 句子切换时平滑移动；关闭后更接近直接切换 |
| 动画时长、提前量 | 调整过渡速度与提前开始滚动的时间 |
| 整体偏移 | 在 −5～+5 秒范围调整所有歌词的显示时机；正值推迟，负值提前 |
| 长间奏倒计时 | 在满足间隔条件时提示即将进入下一句，可调阈值与倒计时时长 |
| 下一句亮度 | 调整即将演唱内容的视觉提示强度 |
| 短句合并 | 把符合长度与间隔条件的短句合并到同一显示块，可调最大段数、分隔符和暗部亮度 |

**整体偏移只影响预览与视频显示，不会重写保存到 LRC/SRT 的原始时间。短句合并只改变显示，不会合并原歌词列表中的行。** 因此微调时仍应选中对应的原句。

### 6.3 视频编码

| 设置 | 建议 |
| --- | --- |
| 编码器 | 默认 x264 使用 CPU；详细模式可查看机器检测到的 NVENC、QSV、AMF 等选项 |
| 质量 QP | 提供 18、22、27 等档位，也可自定义；通常数值越小质量越高、体积越大 |
| x264 预设 | 较慢预设通常用更多计算换取压缩效率，先用默认值即可 |
| 关键帧间隔 | 影响压缩、定位和部分播放兼容性，不确定时保持默认 |
| 音频码率 | 按需要选择；设置为 0 表示不输出音频 |

自动对轴的 CUDA 加速与视频导出的 NVENC 是不同功能。一项可用并不保证另一项也可用。

## 7 保存歌词与生成视频

### 7.1 保存歌词

编辑后点击 **保存歌词** 或按 Ctrl+S。当前文件为 LRC/SRT 时可以保存回该文件；其他情况会提示另存。使用左侧 **另存歌词…** 可以保留原稿并生成新版本。

- LRC 面向歌词播放，时间通常保存到百分之一秒，即 10ms；重新读取可能出现毫秒尾数取整。
- SRT 使用明确的开始和结束时间，适合字幕工作流。
- 原歌词句尾为自动时，保存格式会根据需要推算结束信息。建议再次载入保存结果抽查。

关闭程序、更换歌词或应用新的识别结果时，如果有未保存的编辑，会提示保存、放弃或取消。撤销历史、未保存文本不是可长期恢复的工程文件。

### 7.2 导出视频

1. 试听开头、中间、结尾，尤其检查重复副歌与长间奏。
2. 保存修正后的歌词。
3. 在 **保存到** 选择输出路径，建议使用 `.mp4`，并放在可写且空间足够的目录。
4. 检查分辨率、帧率、背景、字号、编码器及音频码率。
5. 点击 **生成提词器视频**。目标文件已存在时，按提示决定是否覆盖。
6. 等待进度完成；需要中止可取消。取消后的输出不能当作完整成品使用。
7. 完成后打开输出目录或播放视频，检查声音、画面、字幕同步和末尾是否完整。

导出使用开始生成时的歌词与样式快照。修改设置后若要反映到成品，需要重新导出。高分辨率、高帧率、复杂文字效果会增加耗时，CPU 导出不一定达到实时速度。

建议第一次先用简短音频测试，确认目标播放器或提词屏能正常播放，再导出长节目。

## 8 模型下载离线使用和显卡配置

### 8.1 哪些功能需要模型

只有自动对轴需要 Whisper 模型。导入已有 LRC/SRT 后编辑、预览和导出，不需要下载模型。标准绿色包不附带大型模型和 CUDA 运行库。

首次联网下载完成后，保留完整模型目录即可离线使用。不要只复制 `model.bin`，模型还需要配置与分词等配套文件。

### 8.2 模型目录查找顺序

1. 环境变量 `LYRIC_ALIGNER_MODELS` 指定的模型根目录。
2. 程序旁 `models.path` 文件中指定的目录；相对路径以程序目录为基准。
3. 程序旁的 `models` 目录。

保持模型下载器生成的子目录结构。将模型移到其他磁盘时，可使用 `models.path`，例如其内容为 `E:\WhisperModels`。命令行也可以使用 `--models-dir` 指定本次运行的根目录。

### 8.3 拷贝到其他机器

复制整个程序目录，以及实际使用的完整模型目录。如果模型在外部路径，目标机器上需要同步复制并修改 `models.path` 或环境变量。仅复制 EXE 或仅复制快捷方式不够。

NVIDIA 加速还取决于显卡、驱动与所需 CUDA 动态库是否匹配；标准包不保证目标机器的 GPU 环境。GPU 加载失败时先查看错误信息，可以先尝试 CPU，确认模型本身完整。

有 NVENC 选项也应实际导出一段测试视频，避免把驱动或编码限制误认为自动对轴的问题。

## 9 常用制作方案

以下是起步建议，可按目标屏幕调整：

| 场景 | 起步设置 |
| --- | --- |
| 横屏舞台提词 | 1920×1080、30fps、黑底、粗体白字、自动字号、适量上下文 |
| 竖屏提词 | 1080×1920，适当增加行间距，重点检查长句换行 |
| 后期合成 | 按剪辑工程设置分辨率与帧率，选择绿幕或蓝幕，先测试边缘与描边 |
| 快速校对 | 先保持默认画面参数，完成时间轴，再处理视觉样式 |
| 低配置机器 | 先选较小模型试对轴；用 720p/30fps 做导出测试，再决定正式参数 |

## 10 快捷键与常见问题

### 10.1 快捷键

| 按键 | 作用和范围 |
| --- | --- |
| 空格 | 播放/暂停；在文字输入等控件中保留正常输入行为 |
| Ctrl+S | 保存歌词，必要时进入另存流程 |
| Ctrl+Z / Ctrl+Y | 在歌词列表中撤销/重做歌词编辑；输入框内按其自身编辑规则处理 |
| 左/右方向键 | 主播放区域中后退/前进约 2 秒；部分输入、表格控件会优先处理方向键 |
| Esc | 退出全屏预览 |

需要精确选句时优先点击 **上一句 / 下一句**；不要在时间输入框获得焦点时期待方向键控制播放。

### 10.2 常见问题

| 现象 | 检查方法 |
| --- | --- |
| EXE 无法启动、提示缺少 Qt/DLL | 重新完整解压；检查是否只复制了 EXE，或安全软件隔离了组件 |
| 下载源码后找不到 EXE | 到 Releases 下载绿色运行包；源码需要配置开发环境 |
| 只有 TXT，下一步不能直接使用 | TXT 没有时间轴，先自动对轴，或准备准确的 LRC/SRT |
| 歌词整体早或晚 | 先确认音频与歌词版本一致；只修正显示可调整体偏移，需修正文件则编辑原始时间 |
| 某一句不准确 | 选中原句，试听并用 ±200/±50 或打点功能修正；检查相邻句边界 |
| 下方选句不跟随播放 | 检查“跟随播放选句”；文本编辑期间可能暂缓跟随。点击时间轴可重新选句 |
| 歌词显示方框或缺字 | 换用覆盖相应中文、日文或其他字符的字体，必要时加载字体文件 |
| 橙色识别结果很多 | 检查文本顺序、重复段、识别语言、歌曲版本及人声清晰度，人工校对 |
| 模型下载失败 | 切换下载来源，检查网络与磁盘空间；不要把未完成目录当作完整离线模型 |
| GPU 不可用 | 区分对轴 CUDA 与视频 NVENC，检查具体错误、驱动及运行库；尝试 CPU/x264 |
| 导出没有声音 | 检查原音频能否正常试听，以及音频码率是否设为 0 |
| 保存失败 | 换到有写权限的目录，检查文件占用和磁盘空间 |
| 保存后时间有个位毫秒变化 | LRC 常用 10ms 精度；需要毫秒格式可使用 SRT，并抽查结果 |
| 重开后修改丢失 | 检查是否保存了歌词；设置记忆不等于工程和编辑历史自动恢复 |

反馈问题时附软件版本、Windows 版本、CPU/显卡、复现步骤和错误文本；提供音频或歌词前确认可以公开共享。

## 11 独立 Aligner 命令行

项目包含独立入口 `LyricAligner.py` 和 `src/lyric_aligner`。它与主程序共用对轴能力，标准 TeleprompterMaker 绿色包不等于同时附带独立 `aligner.exe`。若使用单独打包的命令行版，请以实际包内 EXE 名称为准。

### 11.1 源码运行示例

在项目根目录、已安装依赖的环境中运行：

```powershell
.\.venv\Scripts\python.exe .\LyricAligner.py --audio "D:\Music\song.wav" --text "D:\Music\lyrics.txt" --out "D:\Music\song.lrc" --lang zh --json "D:\Music\song-report.json"
```

使用外部模型根目录：

```powershell
.\.venv\Scripts\python.exe .\LyricAligner.py --audio "D:\Music\song.wav" --text "D:\Music\lyrics.txt" --out "D:\Music\song.lrc" --model small --models-dir "E:\WhisperModels"
```

独立 EXE 用法相同，例如包内程序名为 `aligner.exe`：

```powershell
.\aligner.exe --audio "D:\Music\song.wav" --text "D:\Music\lyrics.txt" --out "D:\Music\song.lrc" --lang ja
.\aligner.exe --help
```

### 11.2 参数

| 参数 | 说明 |
| --- | --- |
| `--audio` | 输入音频路径 |
| `--text` | UTF-8 逐行歌词文本路径，可带 BOM |
| `--out` | 输出 LRC 路径；与 audio、text 一起提供 |
| `--lang` | 识别语言，默认 auto；常用 zh、yue、ja、en、ko |
| `--model` | 模型标识，默认 large-v3-turbo；可选择 small |
| `--models-dir` | 模型根目录，优先于默认查找路径 |
| `--json` | 额外保存 JSON 报告，便于检查匹配结果 |
| `--no-refine` | 关闭进一步细化时间的步骤 |
| `--enhanced` | 尝试生成带词级时间标签的增强 LRC；并非每行都能生成词级信息 |
| `--gui` | 打开独立对轴图形界面 |
| `--help` | 查看当前版本完整帮助 |

不提供命令行处理参数时会打开图形界面。命令行 `--out` 输出的是 LRC，不能通过把后缀改成 `.srt` 获得 SRT；SRT 请在图形界面使用相应保存按钮。

标准输出会产生 JSON 进度信息，错误写到标准错误。退出码：0 成功、1 执行失败、2 参数错误、130 用户中断。命令执行后请检查退出码、输出文件和 JSON 报告。

增强 LRC 的词级标签不等于主程序逐字高亮功能；主程序以逐句时间轴显示。TeleprompterMaker 主入口也没有提供通用批量视频导出命令。

## 12 源码运行和打包

普通用户可跳过本节。开发者应先阅读根目录的 `requirements.txt` 与 `requirements-dev.txt`，使用兼容依赖版本的 64 位 Python。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe .\TeleprompterMaker.py
```

测试：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
Remove-Item Env:QT_QPA_PLATFORM
```

构建界面翻译资源、生成绿色包的入口见首页与 `build_tools`。开发环境、构建产物、模型和 CUDA 不应直接提交到源码仓库。公开发布前请阅读 [发布准备说明](PUBLISHING.md)。

当前版本没有完整工程文件、云同步、多人协作或通用批量导出界面。本手册只描述 v1.3.0 已有功能；后续规划不代表当前已经实现。
