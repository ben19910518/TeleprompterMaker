# Teleprompter Maker v1.3.0 — 首次源码发布

Windows 提词器视频生成工具，将音频与歌词制作成适合演出、排练和提词屏播放的视频。

## 本版功能

- 两步界面：导入与对轴、格式与微调。
- 导入 LRC/SRT；纯文本歌词自动对轴，支持模型下载与结果试听。
- 修改歌词内容，分别调整开始和结束时间，提供 ±50ms、±200ms 按钮。
- 点击时间轴同步选中下方原句，支持空格播放/暂停、单句试听、插入、删除、撤销与重做。
- 自定义画面、字体、背景、滚动、倒计时与视频导出参数。
- 简体中文、English、日本語界面；首次根据系统语言选择，其他系统语言回退到英文。
- 详细使用手册、实际界面截图和独立 Aligner 命令行说明。

## 下载与运行

本次发布为 **源码版**，采用 **GPL-3.0-only**。下载 Source code 后，按 README 配置 64 位 Python 环境并安装依赖；源码 ZIP 不包含 EXE、Python 运行环境、模型或 CUDA。

完整使用手册：https://github.com/ben19910518/TeleprompterMaker/blob/main/docs/USER_GUIDE.md

现有本地 Windows EXE 包的第三方发行资料仍在核对，因此本次不附加该运行包。对应状态和原因见 THIRD_PARTY_NOTICES.md。模型单独下载，已有 LRC/SRT 的排版和默认 x264 导出不要求 NVIDIA 显卡。

验证：现有 26 项单元测试通过；源码发布清单排除了内部需求、后续规划文档和本机运行数据。
