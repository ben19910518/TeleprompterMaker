提词器视频生成工具 v1.3.0（绿色版，解压即用）
================================================

双击 TeleprompterMaker.exe 启动。不需要安装，所有运行组件都在这个文件夹里，
整个文件夹可以拷到其它 Windows 10/11 电脑直接使用。

界面语言（v1.2 新增）
-------------------
- 菜单「设置 → 界面语言…」可选「跟随系统」「简体中文」「English」「日本語」。
- 默认跟随系统显示语言：中文系统显示中文，日文系统显示日文，其他系统显示英文。
- 手动选择会记住；改回「跟随系统」即可恢复自动选择。切换立即生效，无需重启。
- 切换不改变歌词内容、未提交的编辑、歌词字体或自动对轴的识别语言。
- 主界面、歌词编辑、自动对轴及标准文件对话框均支持中英日。英文和日文快速说明见 README_en.txt、README_ja.txt。


一、基本用法（两步）
--------------------
窗口顶部的步骤条「① 导入与对轴 › ② 格式与微调」可以随时来回切换。

第 ① 步：导入与对轴
1. 「音频」选择歌曲（mp3 / wav / flac / m4a 等）。也可以把文件直接拖进窗口。
2. 在左侧「歌词文本」里粘贴或输入歌词（每行一句），或点「导入文件…」读取 TXT / LRC / SRT。
3. 点「开始识别」自动对轴，在右侧检查结果后点「应用并进入下一步 →」。
   已经有带时间轴的 LRC / SRT 时，导入后直接点「已有时间轴，直接下一步 →」。

第 ② 步：格式与微调
4. 左边设置提词器画面格式；中间是实时预览：调任何设置都会立刻看到效果；可以播放、拖动时间轴、
   点歌词列表跳转（空格 播放/暂停，← → 快退快进，↑ ↓ 上一句/下一句）。
5. 下方「本句微调」可以精调每一句的起止时间和文字（见第四节）。
6. 选择「保存到」的位置，点「生成提词器视频」。
   输出 H.264（固定量化 CQP）+ AAC 的 MP4，画面静止时几乎不占空间，
   一首 4 分半的歌 1080p 约 15 MB（无动画）/ 40 MB（有滚动动画）。

「全屏预览」可以把画面全屏显示到第二块屏幕上，直接在真实提词屏上检查字号和亮度。


二、主要设置
------------
- 简易模式 / 详细模式：右上角切换。详细模式里有全部参数。
- 背景颜色：黑色用于提词屏；绿幕 / 蓝幕用于抠像；也可以自选颜色。
- 字体、字重、中间行字号（默认「自动铺满屏幕」）、上下行比例、字间距、行间距、显示行数。
- 一句太长超出屏幕时自动折成两行，这两行之间的「折行行距」更紧，能看出是同一句。
- 越往外的行越暗（详细模式可调「相邻行亮度 / 最远行亮度」）。
- 过渡动画：开 = 平滑滚动；关 = 直接切换，文件更小。
- 前奏/间奏提示：间奏较长时，下一句会提前移到中间（暗色等待），开唱前出现 ●●● 倒计时。
- 短句合并：很短的几句（如「在春天」「在夏天」）合成一行，中间用 ／ 分隔，
  正在唱的那一小句高亮，其余变暗，能看出这是合并出来的。
- 分辨率（含竖屏和自定义尺寸）、帧率、画质（QP 值）、编码器（有 NVIDIA 显卡时可用 NVENC）。


三、只有纯文本歌词时：自动识别时间轴
------------------------------------
1. 在第 ① 步粘贴歌词或导入 txt（一行一句）。在第 ② 步时也可以点「← 重新对轴」回到这里。
2. 第一次使用需要下载识别模型（约 1.6 GB，国内选 ModelScope 下载源很快），
   下载一次后保存在本文件夹的 models 目录里，以后可以离线使用。
3. 点「开始识别」：程序听歌并给每一行配上时间（CPU 上一首歌约 1~2 分钟）。
4. 检查结果：橙色行 = 没听清，时间是估算的；双击时间可以修改，「试听选中行」可以核对，
   标题、作者这类不唱的行可以「删除选中行」。
5. 「应用并进入下一步 →」后会自动在歌词旁边保存一份 .lrc；也可以另存为 LRC / SRT。


四、主界面歌词编辑（v1.1 新增）
--------------------------------
- 第 ② 步下方「歌词与时间轴」列表显示原始歌词行与起止时间，不受预览短句合并影响。点击选句并跳转预览。
- 点击或拖动时间轴会同步选中下方原句，并刷新编辑区，可立即用加减按钮调节起止时间。
  即使关闭「跟随播放选句」也生效；短句合并时按点击位置定位合并块内的原句。
- 选中句后，使用「开头 −50ms / +50ms」「结尾 −50ms / +50ms」精调时间。
  每个 50ms 按钮正下方新增对应的 200ms 按钮，方便粗调后再精调。
- 主界面按空格播放/暂停，点过微调按钮后同样有效；歌词、时间等输入框聚焦时保留正常输入。
- 也可直接输入开始、结束时间（分:秒.毫秒或秒数）；结束留空表示自动，旁边显示推算值。
- 在文本框修改歌词，支持换行显示原文和翻译。点击「应用修改」生效，切换句子或保存也会提交。
- 「此刻设为开始 / 结束」用当前播放位置打点；「试听本句」播放选中句前后的一小段。
- 支持「后插一句」「删除本句」及最多 100 步撤销/重做。表格聚焦时 Ctrl+Z / Ctrl+Y。
- 「保存歌词」或 Ctrl+S 保存当前 LRC/SRT；左上「项目」里的「另存歌词…」可选择新路径或格式。
- 关闭窗口或换歌词前会提醒未保存修改。保存失败会保留修改状态，便于重试。
- 选句或编辑后不会被播放自动切走；需要时勾选「跟随播放选句」。
- 编辑区显示原始歌词时间，不包含预览的整体偏移；播放位置打点会自动扣除该偏移。
- 时间不允许为负、倒序或句尾越过下一句。自动句尾若正好等于下一句开始，不能再右移。
- LRC 用额外空时间标签保留提前结束的句尾；其他播放器对这类标签的显示可能不同，
  需要明确保留字幕起止区间时也可另存 SRT。LRC 保存精度为 10ms。
- 纯文本歌词的时间是预览临时值，请先自动识别生成时间轴后再保存。


五、文件夹说明
--------------
TeleprompterMaker.exe   主程序
_internal\              运行组件（请勿删除）
models\                 识别模型（自动识别时间轴时下载到这里）
fonts\                  放进 .ttf / .otf 字体文件，启动时自动加载（不用安装字体）
settings.json           自动保存的设置（删除即恢复默认）
error.log               出错时的记录，反馈问题时请附上


六、常见问题
------------
- 第一次打开如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（程序未做数字签名）。
- 识别速度：自动尝试 NVIDIA 显卡，不可用时回退 CPU。需要兼容的驱动与 CUDA 12 运行库
  （cuBLAS、cuDNN 9）；也可以把这些 DLL 放进本文件夹下的 cuda 目录。
- 歌词和音乐整体有偏差：详细模式 → 动画与时间 →「整体偏移」。
- 想让演员更早看到下一句：详细模式 →「提前切换」，或「当前行位置」设为上方 2 句、下方 4 句。
