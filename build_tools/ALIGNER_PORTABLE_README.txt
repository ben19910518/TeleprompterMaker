Lyric Aligner 歌词自动对轴工具
离线便携版 · Windows x64 · 打包日期：2026-10-23

一、软件介绍
根据音频和用户提供的歌词，为每一行歌词生成开始和结束时间。支持自动识别、时间校正、分句试听，以及导出 LRC 歌词和 SRT 字幕。内置 Large-v3 Turbo 模型，支持中文、粤语、日语、英语、韩语及自动语言检测。识别在本机进行，使用已附带模型时无需联网。
这是一款歌词对轴工具；使用时需要准备歌词文本。音乐伴奏、合唱、混响、口音、重复段落和歌词版本差异都可能影响结果，导出前请试听检查。

二、复制与启动
1. 将整个 LyricAligner_Portable 文件夹拷贝到另一台电脑的本地可写目录。
2. 双击 LyricAligner.exe。首先选择音频，随后进入歌词对轴窗口。
3. 不需要安装 Python，也不需要启动脚本。Python、Qt、音频解码库、CUDA/cuDNN 运行库及模型均随包附带，不需要另装 CUDA Toolkit。
4. 目标电脑需要 Windows 64 位系统及已安装的 NVIDIA 显卡驱动。建议使用 Windows 10/11 和更新后的 NVIDIA 官方驱动；GPU 型号、显存、驱动须支持附带运行库。仅有 NVIDIA 显卡并不代表所有旧型号都能加速。
5. 请完整解压后运行，不要在压缩包内直接运行，不要只复制 EXE。为程序、输出及音频预留足够空间，软件目录大小见“打包清单.json”。

三、使用步骤
1. 选择 WAV、MP3、FLAC、M4A 或 OGG 音频。建议使用人声清晰、与歌词版本一致的音频。
2. 在左侧直接粘贴歌词；也可点击“粘贴剪贴板歌词”或“导入文本（可选）”。推荐 UTF-8 的纯文本 TXT，每行一句，空行会忽略。请去掉歌名、作者等不演唱的内容；已有 LRC 建议先去掉时间标签后再导入。
3. 选择正确的“语言”，识别模型选择“Large-v3 Turbo”。随包已带此模型，应显示“已下载”。Small 模型未附带，切换后可能需要下载。
4. 点击“开始识别”。模型加载和首次识别可能需要等待，实际耗时取决于音频长度和硬件。
5. 识别时状态栏出现“显卡加速”表示使用了 NVIDIA GPU；如果显示“CPU”，表示当前 GPU 环境未成功启用，程序已回退 CPU。
6. 在右侧结果中检查时间与歌词。橙色表示识别较弱或时间由前后估算，应优先核对。
7. 选中一行或多行，点击“试听选中行”；双击歌词或序号也可以试听。双击“开始”或“结束”时间可以修改，建议沿用表格显示的时间格式。不要让结束时间早于开始时间。
8. 不需要的结果行可选中后点击“删除选中行”。若要改歌词文字，请修改左侧文本后重新识别。
9. 点击“保存为 LRC…”或“保存为 SRT…”，选择输出位置。LRC 用于歌词播放器，SRT 用于字幕软件。请先保存再关闭窗口。
10. 处理另一首歌时重新打开程序并选择音频。

四、目录内容
LyricAligner.exe         图形界面入口，日常使用双击此文件。
aligner.exe              命令行入口，供批处理或程序调用。
_internal/               Python、Qt、识别和音频解码等程序依赖，不要删除。
cuda/                    NVIDIA CUDA/cuDNN 动态运行库，不要删除。
models/large-v3-turbo/   已下载的离线模型，包括隐藏的 .complete 文件。
models.path              内容为相对路径 models，保证模型随文件夹迁移。
licenses/                NVIDIA 分发包中的许可及说明文件。
使用说明.txt             本说明。
打包清单.json            文件大小、SHA-256 和运行库来源版本。

五、常见问题
· 提示模型未下载：确认 models/large-v3-turbo 中的文件和 .complete 都已完整复制。不要把模型目录多套一层；models.path 应只有 models。如果设置过 LYRIC_ALIGNER_MODELS 环境变量，它会优先覆盖包内模型位置，请清除或修正。
· 有 NVIDIA 显卡却显示 CPU：更新显卡驱动并重启，检查 cuda 和 _internal 是否完整，以及显存是否被其他程序占满。老旧 GPU 或驱动不兼容时可能只能使用 CPU。驱动须在目标电脑安装，无法靠复制软件目录替代。
· 双击没反应或报缺少 DLL：先确认已完整解压，没有单独移动 EXE；检查安全软件是否隔离了文件。可使用命令行入口查看错误，向维护者提供报错文字。
· 试听暂时没有声音：等待音频准备完成，检查系统输出设备、音量及音频本身。
· 结果错位：核对音频和歌词版本，尽量按实际演唱顺序逐行输入，保留重复演唱的行；对橙色行试听并手动修改。
· 输出未生成：识别完成后仍需点击保存按钮并选择路径。

六、命令行使用（可选）
在软件目录打开终端后执行：
.\aligner.exe --audio "D:\Music\vocals.wav" --text "D:\Music\lyrics.txt" --lang ja --out "D:\Music\lyrics.lrc" --json "D:\Music\report.json"
语言参数：auto、zh、yue、ja、en、ko。默认模型为 large-v3-turbo。
可加 --enhanced 请求增强 LRC；仅对可靠且文本一致的匹配写入逐字时间，不能保证每一行都有逐字时间。JSON 保存识别与匹配详情。
成功退出码 0，识别失败 1，键盘中断 130。图形界面入口无需这些参数。
