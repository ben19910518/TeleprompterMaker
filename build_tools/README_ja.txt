プロンプター動画作成 v1.3.0 — Windowsポータブル版

フォルダー全体を展開して、TeleprompterMaker.exe をダブルクリックしてください。
_internal は削除・移動しないでください。Pythonのインストールは不要です。

表示言語
「設定 → 表示言語…」で「システムに合わせる」「简体中文」「English」「日本語」を選べます。
初期設定はシステムに合わせます。中国語環境では中国語、日本語環境では日本語、
それ以外では英語を表示します。手動で選んだ言語は保存されます。
変更はすぐに反映され、歌詞・編集中の内容・フォント・再生位置は保持されます。
表示言語と、歌詞の自動同期で使う認識言語は別の設定です。

基本操作
画面上部のステップ（「① 読み込みと同期 › ② 書式と微調整」）でいつでも切り替えられます。
ステップ① 読み込みと同期
1. 音声ファイル（MP3 / WAV / FLAC / M4Aなど）を選択するか、ウィンドウにドラッグします。
2. 歌詞を貼り付け・入力（1行1フレーズ）するか、「ファイルを読み込む…」でTXT / LRC / SRTを読み込みます。
3. 「自動同期を開始」を押し（必要ならモデルをダウンロード）、結果を確認して「適用して次へ →」を押します。
   タイミング付きの歌詞（LRC / SRT）は「同期済み、次へ →」でスキップできます。
ステップ② 書式と微調整
4. 文字や画面の設定を調整し、プレビューします。入力欄以外ではスペースで再生／一時停止できます。
5. 一覧または時間軸で行を選び、開始／終了の ±50ms・±200ms ボタンで調整します。
   歌詞や時刻を直接編集した場合は「変更を適用」で確定します。行の切り替えや保存でも確定します。
6. Ctrl+Sで歌詞を保存します。「歌詞を別名で保存…」でLRC／SRTを出力できます。
7. 保存先を指定して「プロンプター動画を作成」を押します。

歌詞編集について
一覧は元の歌詞行を表示します。プレビュー上の短い行の結合とは独立しています。
編集時刻には全体オフセットを含みません。終了を空欄にすると自動で推定します。
「現在位置を開始に／終了に」で再生位置を打刻できます。変更は元に戻す・やり直すで取り消せます。
時刻を負の値や逆順にはできません。終了は次の行の開始を超えられません。
推定と表示された行は、試聴して確認してから出力してください。

ファイルとモデル
この標準版にはアプリの実行環境と翻訳を含みますが、認識モデルとCUDA実行ライブラリは含みません。
認識モデルは models に保存されます。既存環境の models を丸ごとコピーすればオフラインで使えます。
CUDAのDLLはEXEと同じ階層の cuda フォルダーに配置できます。対応するNVIDIAドライバーが必要です。
GPUが使えない場合はCPUに切り替わります。フォントは fonts に置くと起動時に読み込まれます。
設定と表示言語は settings.json に保存します。問題を報告する際は error.log を添付してください。
